# 보안

릴레이는 공개될 수 있다는 전제로 줄였습니다.

- 루트 토큰이 없으면 마을을 만들지 못합니다. 루트 토큰은 환경 변수 `RELAY_ROOT_TOKEN`만 읽습니다.
- 커넥터 토큰, 월드 토큰, 리프레시 토큰, 페어링 코드는 평문으로 저장하지 않습니다. 비교는 SHA-256과 `timingSafeEqual`입니다.
- 토큰은 마을 하나에만 묶입니다. 역할이 다르면 403입니다. 월드 토큰으로 커넥터 폴링을 할 수 없고, 커넥터 토큰으로 목표를 넣을 수 없습니다.
- 페어링 코드는 10분, 한 번입니다. 리프레시 토큰은 돌리면 이전 값이 재사용되지 않습니다.
- `issuedAt`이 5분 창 밖이면 새 명령은 거절됩니다. 같은 `commandId`와 같은 본문은 멱등하게 같은 순번을 돌려줍니다.
- 허용 명령은 `goal.submit`, `decision.answer`, `character.bind`뿐입니다.
- 릴레이는 자식 프로세스를 띄우지 않습니다. git, 셸, 데스크톱, Claude 실행 타입은 저장하지 않습니다.
- 쓰기와 머지는 커넥터 로컬의 승인 뒤에만 다룹니다. 이 슬라이스의 머지는 아직 없고, 릴레이는 그 명령을 거부합니다.
- Claude 드라이버 기본값은 꺼짐입니다. 켜져 있어도 쓰기 턴은 승인이 `allow`일 때만 `spawn`하며 `shell`은 켜지 않습니다.
- `agent-desktop`은 컴퓨터 사용 CLI일 뿐 모델 루프가 아닙니다. 어댑터는 플래그와 상관없이 호출을 거절하고 포트를 열지 않습니다. 릴레이 명령으로 데스크톱을 호출하는 경로는 없습니다.
- 워크트리 격리와 "push 금지"는 AgentCraft에 있습니다. 여기는 아직 워크트리를 만들지 않습니다. 만들지 않은 것을 막았다고 쓰지 않습니다.
- 프로필과 릴레이 상태 파일은 `.gitignore` 대상입니다. 예시 설정에 비밀을 넣지 않습니다.
- 로그는 토큰을 찍지 않도록 바이너리 쪽 출력을 주소와 상태 문장으로 제한했습니다. 목표 문장은 사무실 상태에 남습니다. 릴레이 운영자는 목표 문장을 볼 수 있습니다. 비밀을 목표 문장에 넣지 마세요.

월드 토큰은 서버 스크립트 메모리에만 두는 설계입니다. 맵 파일이나 저장소에 적지 마세요. 서버가 재시작하면 페어링을 다시 합니다.
