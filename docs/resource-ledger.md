# 리소스 장부

메이플 리소스를 저장소에 넣지 않습니다. 공식 Resource Storage는 파일을 받아 가는 곳이 아니라, 크리에이터 안에서 RUID로 고르는 목록입니다. 아래 칸은 비어 있습니다. 추측한 RUID를 적지 않습니다.

| 용도 | 이름 | RUID | 공식 출처 | 허용 범위 | 액션 | 확인일 |
| --- | --- | --- | --- | --- | --- | --- |
| 세션 NPC 몸 | 미정 |  | AvatarItem 분류만 확인 (hair, face, hat, coat, eyeaccessory). 품목 미선택 | 월드 안에서만 사용 예정. 파일로 반출하지 않음 | 미정. legacy 시트는 쓰지 않음 |  |
| 이름표 | 텍스트 |  | NameTagComponent | 서버가 준 activity 문자열 | 없음 |  |
| 책상·책장 | 도형 또는 텍스트로 대체 |  | Sprite 후보는 크리에이터에서 검색 | 외부 추출 이미지 금지 | 없음 |  |
| 걷기·서기 | 없음 |  | AvatarStateAnimationComponent의 비legacy 시트는 문서에 있음. 목록은 미확인 | 클립을 코드에 넣지 않음 | 없음 |  |
| 효과음 | 없음 |  | AudioClip | 사용하지 않음 | 없음 |  |

확인한 공식 페이지는 설계 초안에 적힌 Creator Center 문서입니다. 이 표는 그 페이지를 다시 열람해 품목을 고르지 않았습니다. 게시와 배포는 하지 않습니다.

IP 범위, 협업 에셋 제한, 공식 게임으로 오인되는 복제는 최신 제작 가이드를 크리에이터에서 다시 봐야 합니다. 이 저장소는 비공식입니다.
