# 기능 대조

기준은 업스트림 `blendi-remade/agentcraft`와 포크 `CapybaraVision/agentcraft`의 같은 커밋 `8fe3ad23489b06f9142c6382bc23d31090c6b406`(2026-10-08)입니다. 예전 메모의 `9411705`는 그 이전이었습니다. 마인크래프트 화면과 모드 에셋은 포팅 대상이 아닙니다. 상태는 이 저장소 기준입니다. 크리에이터 플레이로 확인한 항목은 따로 적습니다.

상태 뜻:

- **구현**: 자동 테스트가 그 동작을 실행합니다.
- **목업**: 계약과 가짜 구현이 있고, 실제 외부 프로그램은 실행하지 않았습니다.
- **미검증**: 메이플 크리에이터에 붙여야 하는 소스만 있습니다. 월드에서 실행해 보지 않았습니다.
- **계획**: 이 슬라이스에 없습니다.

## 이 PR의 수직 슬라이스 인수

자동 테스트로 확인하는 경로:

1. 월드 토큰으로 `goal.submit`.
2. 커넥터 폴링이 과제를 만들고 질문을 연다.
3. 작업자 세션은 `ses_worker`, 장소는 `user`.
4. 같은 `commandId`를 다시 보내도 목표는 하나다.
5. 커넥터 프로세스를 새로 만들어도 세션 ID가 같다.
6. `decision.answer`의 `이대로 진행` 이후 목표는 `done`, 장소는 `desk`.
7. 다른 마을 토큰의 상태에는 이 목표가 없다.

여기까지가 첫 슬라이스입니다. 위 표의 계획 행을 구현했다고 보지 않습니다.

## 아직 없는 업스트림 기능

이 목록을 구현했다고 보지 않습니다.

- 과제 의존성, 재배정, 우선순위, CI, 취소
- 추가 워커 캐스트, 색, 스킨, 아바타 RUID, 걷기 클립
- `lounge` `terminal` `testbench` `mergestation` `meeting` 장소로의 실제 이동
- Allow once / Always / Deny 정책 엔진과 별도 권한 카드
- 리드 리뷰 상태와 리뷰 화면
- 파일 단위 diff, 헝크, 작업 트리, 머지 스테이션. 머지와 푸시는 거부만 있음
- 에이전트 jsonl, 모니터, `@이름`, pause/resume/stop
- 마크다운 기억, Codex, HQ 건설, 램프, 카메라
- 길찾기. 이동은 직선 `SetWorldPosition` 스크립트이며 크리에이터에서 보지 않음
- 가구, 조명, 배경음. `docs/polish-backlog.md`에 대기
- 공개 443 엔드포인트. 계정이나 클라우드 배포는 만들지 않음
